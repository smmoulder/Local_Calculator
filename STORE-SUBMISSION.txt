Suggested listing
Name: Local Model Calculator
Short description: Plan local AI model memory before you download.
Description: Estimate GPU memory for local GGUF models. Explore weight
precision, context length, KV cache, offloading, overhead and headroom.
Search public Hugging Face GGUF repositories and compare estimated memory
fit. Import Windows DxDiag text or Mac XML System Information reports
locally. Includes dedicated VRAM and Apple silicon unified-memory planning,
explanations, and light and dark themes. No models are downloaded or run.
Results are planning estimates, not measured benchmarks or compatibility
guarantees. Manual calculations work offline; discovery needs internet.
Support: https://github.com/smmoulder/Local_Calculator/issues
Category: Developer tools
Release notes: First standalone Windows release.

Certification notes: Full-trust desktop Electron app. No administrator
privileges, drivers, background service, account, or model runtime needed.
File import is user initiated and parsed locally. Network discovery calls
the public Hugging Face API. Documentation and optional support links open
in the default browser. No feature is gated behind payment.
